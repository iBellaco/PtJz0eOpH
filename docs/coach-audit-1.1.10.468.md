# Coach 1.1.10.468 — build 1184

## Proceso de validación

- Se añadió la instrucción permanente de no consultar continuamente el estado
  de las validaciones automáticas.
- Después de iniciar una validación se comparte una sola vez el enlace y el
  estado inicial; las consultas posteriores requieren aviso o petición expresa
  del propietario.

## Verificación

- Se comprobó que la instrucción conserva el flujo manual de integración y no
  modifica la corrección funcional de anuncios patrocinados.
